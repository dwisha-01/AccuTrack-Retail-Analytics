# AccuTrack Retail Analytics

## Overview

AccuTrack is an AI-powered retail analytics platform that uses computer vision and deep learning to monitor crowd activity, analyze customer movement, and detect anomalies in retail environments.

The system processes video streams in real time using YOLOv8-based object detection and provides insights that can help retail stores improve customer experience, optimize staffing, and enhance security.

---

## Features

### Implemented Features

* Person detection using YOLOv8
* Real-time video processing
* Crowd density monitoring
* Anomaly detection using the UCSD Anomaly Dataset
* Flask-based web interface
* Live analytics visualization

### Planned Features

* Customer tracking across multiple zones
* Footfall analytics
* Dwell time analysis
* Heatmap generation
* Customer re-identification (Re-ID)
* Overcrowding alerts
* Retail performance dashboard
